# Manuscript

This directory contains the final version-12 manuscript.

- `moulla_2026_space_time_stokes_dirac.tex`: self-contained LaTeX source.
- `moulla_2026_space_time_stokes_dirac.pdf`: compiled 55-page paper.

Build from the repository root with:

```bash
make paper
```

The checked-in PDF is the visually inspected reference artifact. A local rebuild may differ at the byte level because PDF metadata and TeX versions can vary.
